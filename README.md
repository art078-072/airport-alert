# ✈️ Airport Alert

Оповещения в Telegram по аэропортам **Шереметьево, Внуково и Пулково**:

- 🔴/🟢 введение и снятие временных ограничений (закрытий) — обычно из-за атак беспилотников.
  Источник — официальные Telegram-каналы аэропортов (@svo_online, @vnukovoairport_VKO, @pulkovo_led),
  Росавиации (@favt_ru, @korenyako) и Аэрофлота (@aeroflot);
- 🟠 массовые задержки — больше 5 вылетов задержаны на 60 минут и дольше
  (онлайн-табло svo.aero, pulkovoairport.ru и aer.aero; Внуково — через avionio.com, своё табло vnukovo.ru закрыто антибот-защитой).

Проверка запускается GitHub Actions каждые 10 минут. Список подписчиков и состояние
хранятся в кэше Actions (в репозитории только код).

**Подписаться:** открыть бота в Telegram и нажать Start. Отписаться: `/stop`.

**Отслеживание рейса** (табло Шереметьево, Внуково, Пулково и любых других аэропортов через avionio.com — так видны рейсы Аэрофлота из регионов; aeroflot.ru закрыт для ботов и зарубежных IP):
- `SU284 21.09` (без даты — сегодня) — статус рейса и сразу слежение до прилёта: бот сообщит об изменениях времени, статуса, терминала, выхода, ленты багажа; `/my`, `/untrack SU284`;
- прислать билет — PDF (в том числе скан), фото или скриншот маршрутной квитанции — или переслать письмо с бронированием;
  бот отвечает «Отслеживаю рейс SU1367, дата 18.09.2026» и ставит каждый рейс на слежение до прибытия.
  Фото распознаёт Tesseract (ставится на раннер только при получении фото, ~15 с) (появление на табло, изменения времени/статуса/выхода/ленты багажа).

Бот обрабатывает команды при каждом запуске, поэтому ответ приходит в течение ~10 минут.

## Настройка (Settings → Secrets and variables → Actions)

| Secret        | Значение                         |
|---------------|----------------------------------|
| `TG_BOT_TOKEN`| токен бота от @BotFather         |
| `TG_CHAT_ID`  | (необязательно) chat_id владельца |
